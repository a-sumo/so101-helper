SO-101 HELPER

SO-101 setup

Connect your own SO-101 to the Lens over a trusted local connection, inspect its calibration, or edit the assembly sequence.

Connect the robot

This is local robot control, not a remote-control service. Every owner runs the bridge and trusted helper on the computer physically connected to their arm. Commands and telemetry stay on that LAN; the hosted service handles only DNS, certificate proof, and a one-time pairing code.

SO-101 LensSpectacles
  1. Complete the SO-101 assembly and calibration guide ↗.
  2. Connect USB logic power and DC servo power.
  3. Clone the helper repository, create a Python 3.11 virtual environment, and install requirements-bridge.txt.
  4. Enroll this computer once using the owner's certificate email. .venv/bin/python bridge/local_wss_helper.py setup --email owner@example.com
  5. Start the USB bridge in Terminal 1. .venv/bin/python so101_bridge.py
  6. Start first-time pairing in Terminal 2. .venv/bin/python bridge/local_wss_helper.py serve --pair
  7. Launch the Lens on physical Spectacles. Enter Terminal 2's eight-digit code in the system PIN keyboard that appears inside the Lens—not in Cloudflare or Lens Studio.
  8. Clear the workspace, type ARM in Terminal 1, then type enable in Terminal 2.
  9. Open Operate, select Real arm, wait for ARM LIVE, and begin with a small motion.
