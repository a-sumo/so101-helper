SO-101 LensSpectacles
  1. Complete the SO-101 assembly and calibration guide ↗.
  2. Connect USB logic power and DC servo power.
  3. Start the local bridge. uv run --python 3.11 --with-requirements requirements-bridge.txt python so101_bridge.py
  4. Enter the printed bridge address in the Lens.
  5. Clear the workspace, then type ARM when the Lens connects.
  6. Open Operate, select Real arm, and align the virtual and physical bases.
